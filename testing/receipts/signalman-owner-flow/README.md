## Owner association correction

The headed check found that selecting T114 after V4 left the old `v`
association in the field. The test explicitly changed it to `t` before
collection. The accompanying state patch clears the association when selection
changes or a survey loses the selected device, and preserves same-device
reselection. This prevents silently carrying an owner label to another board;
it does not turn a COM-port name into authenticated stable identity.

Automated verification of the accompanying patch: all seven
`availability_face` tests and all three association state tests pass, locked
and offline, using the unchanged host pins. The native desktop binary builds;
formatting and diff checks pass. The new focused-text test exercises injected
Unicode and keyboard export; it deliberately does not claim clipboard support.
